# 📚 Préstamos de la biblioteca

Proyecto base para una actividad de ejercicio: **experimentar qué pasa cuando le pedimos algo a una inteligencia artificial sin especificar los detalles**.

- **Curso:** 6° Año
- **Asignatura:** EDI

## De qué se trata

Es una página web sencilla que registra los libros prestados de la biblioteca. Cada préstamo guarda el **título del libro** y el **nombre del alumno**.

La página funciona, pero está **incompleta a propósito**. Durante la actividad, cada grupo le va a pedir a una IA (ChatGPT o Gemini) que le agregue algo, usando una sola frase y sin dar detalles. Después vamos a analizar qué decidió la IA por su cuenta y si el resultado era lo que esperábamos.

La consigna completa, con el paso a paso y las preguntas, se entregará impreso.

## Cómo descargar desde el enlace

1. Botón verde **Code** → **Download ZIP**.
2. Descomprimí el archivo (clic derecho → *Extraer todo*).
3. Abrí la carpeta `biblioteca-prestamos-main` y hacé doble clic en `index.html`. Se abre en el navegador.

No hace falta instalar nada: solo un navegador.

## Archivos

| Archivo | Qué tiene |
| --- | --- |
| `index.html` | La estructura de la página: el formulario y la lista de préstamos. |
| `estilos.css` | El diseño: colores, tamaños y ubicación de los elementos. |
| `app.js` | El comportamiento: los préstamos de ejemplo y cómo se agrega uno nuevo. |

## Stack Tecnológico

HTML, CSS y JavaScript, sin frameworks ni librerías externas. Los datos se guardan solo mientras la página está abierta: al recargarla vuelven los préstamos de ejemplo.
